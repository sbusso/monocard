Changelog

0.1.2

25 November 2026

  • The app says when a new version of Monocard is out. It asks GitHub once a day and sends only the version number. The switch is in Settings, About. It does not install the update.
  • The app and the command line show Monocard’s version and the version of Greycard that it is built on.
  • Report a problem opens Monocard’s own form.
  • Crop guides: golden ratio, golden spiral, diagonals and triangles. O steps through them.
  • Past 100%, each picture pixel is drawn as a block.
  • Panels scroll more smoothly, and a screen reader hears more of the window.
  • Built on Greycard 0.12.0 and the 191 changes after it. Greycard’s changelog has the list. Its color tools are not in Monocard.

Edits are saved in a new format. 0.1.2 reads the edits of 0.1.0 and 0.1.1. They cannot read an edit that 0.1.2 saved. To be able to go back, keep a copy of your .mcd files.

Release 0.1.2 on GitHub, with the checksums.

0.1.1

24 November 2026

  • The line over the histogram shows the grey value alone.
  • A damaged DNG that claims an impossible size is refused. On Linux it ended the program.
  • Measuring the sensor is in Settings, Camera profiles.
  • The log has Monocard’s own lines, and messages say Monocard.
  • The url library is updated (RUSTSEC-2026-0592).

Release 0.1.1 on GitHub, with the checksums.

0.1.0

24 November 2026

  • The first release. For Apple silicon Macs, signed and notarized.
  • Linux and Windows, for 64-bit Intel and AMD.
  • Import from the camera by USB, on the Mac.
