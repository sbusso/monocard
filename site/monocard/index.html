Monocard

The darkroom for monochrome sensors.

Monocard is a free, open source raw editor for cameras with no color filter on the sensor. It develops one channel from the raw data to the print. Its first camera is the Ricoh GR IV Monochrome. It opens any true monochrome DNG.

What it does

  • One channel

    No demosaic, no white balance, no color conversion. A monochrome camera's JPEG is edited the same way. Color photos are not listed, and no color tool is offered.

  • Profiled denoise

    A noise model for each ISO, with non-local means or wavelets, and a slider that keeps some of the sensor's grain.

  • Dodge and burn by zone

    A nine zone tone equalizer that keeps to edges, and a view of the picture in zones 0 to X.

  • Contrast by scale

    Local contrast, a contrast equalizer from fine texture to large forms, and deblurring for a sensor with no anti-aliasing filter.

  • Highlights

    A map of what the sensor clipped, a shoulder into white, a smooth edge around clipped light, and a bracket merge.

  • Looks, grain, and toning

    Ten built-in looks that stay editable, grain that follows the tones, solarize, and split toning. Looks are small text files.

  • Masks

    Brush, gradient, luminance range, subject, and sky. Each drives the same tone tools.

  • Grey output

    Grey JPEG and 16-bit grey TIFF, a grey proof on matte, baryta, and newsprint, and color only where a print is toned.

  • Beside Greycard

    Monocard keeps its own settings, library, and sidecars. It reads Greycard's edits as a start and never changes them.

Limits

  • There is no release yet. Monocard is built from source.
  • The profile for the Ricoh GR IV Monochrome is not calibrated. It holds no measurements until calibration frames have been shot.
  • The learned monochrome denoiser is not trained. The profiled and the wavelet denoisers are what works now.
  • The Solar looks are not yet matched against the camera's own files.
  • Clipped light is lost. A monochrome sensor has no other channel to recover it from, so Monocard shapes the way into white and does not claim more.
  • There are no red, yellow, or green filters in software. The color was not recorded. Use a filter on the lens.

Build it

cargo build --release -p greycard-ui --features mono --bin monocard-ui
cargo build --release -p greycard-cli --features mono --bin monocard

The source tree's docs/monocard/README.md has the rest.
